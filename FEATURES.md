## Status legend

Every label answers ONE question: does working code exist — and if not, why
not?

| Status                    | Meaning                                                                                                                                                |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 🟢 `FULLY_FUNCTIONAL`     | Works as intended, exercised by tests or daily use.                                                                                                    |
| 🟡 `PARTIALLY_FUNCTIONAL` | Ships but has known gaps, edge-case bugs, or missing pieces.                                                                                           |
| 🔴 `BROKEN`               | Present in code but failing. Keep BROKEN nameable — "zero BROKEN rows" is itself information.                                                          |
| 🔵 `DISABLED`             | Code exists and is correct, but execution is externally switched off (flag, missing credentials, CI off). A switch, not a fix — never fold into BROKEN. |
| ⚪ `PLANNED`              | No code yet; genuinely next on the build path.                                                                                                         |

> A feature earns `FULLY_FUNCTIONAL` only when you can point to the code that
> delivers it AND confirm it works. If you're unsure, it's
> `PARTIALLY_FUNCTIONAL` at best, never round up.

## Collection lib (`lib` — systemd hardening spine)

Evidence basis for this section — three evidence classes, mechanically
applied (status is a pure function of class):

- **Class A** — exercised by an in-repo check (VM test, eval-contract,
  negative mutation leg, lib eval test).
- **Class B** — extraction byte-parity proven at extraction time (CHANGELOG)
  AND at least one SystemNix fleet consumer file (verified by grep, 2026-11-12:
every helper below has one — `serviceTypes` 11, `mkFilesystem` 10,
`mkStateDir` 24, `ioTier` 63, …).
- **Class C** — parity only, no consumer, no in-repo test.

A → 🟢, B → 🟢 (Notes say when no dedicated in-repo test exists), C → 🟡.
A known behavioral limitation forces 🟡 regardless of class.
