- **options-json provenance check (2026-11-12)** — NEW `tests/options-json.nix` → `checks.*.options-json` (pure eval, both systems): renders every module's own options (`services.<name>*`, `_module.*` internals excluded) to JSON and mechanically proves the path-provenance claim behind paths-not-imports — all 4 modules, 40 options, every declaration resolving inside its `modules/<name>/` dir. Finding banked: option declarations for a path-exposed module carry the module DIRECTORY (no `/default.nix` suffix); `lib.optionAttrSetToDocList` is the flattening tool (top-level `attrNames` never sees nested options). No import-apply negative leg by design: the modules are functions, so import-application cannot evaluate — the flake `modulesArePaths` assert plus eval semantics already exclude that shape (documented in the test header).
- **lib eval contracts + a real bug found + aarch64 un-gate (2026-11-12)** — NEW `tests/lib-eval.nix` → `checks.*.lib-eval`: 53 pure-eval contracts over the collection lib (harden family incl. the lowercase `memoryMax` trap and override passthrough; `extractPortLiterals` all three forms + zero-padded drop + range filter + model-tag exclusion + the `word:NNN` limitation pinned as KNOWN; `unitExecText` all 7 Exec keys + both Environment forms; `mkPoolDirUnit`/`mkSqliteBackupUnit`/`mkMetricTextfileCollector` unit shapes via a module-system `types.anything` merge; `mkPortGuard` empty-owner throw + owner-spare pattern; `serviceTypes` all 4 helpers; `mkFilesystem` contamination throw + extra-attr round-trip). **Found and fixed a real bug on first run**: `parseMemoryBytes` crashed on bare-byte `MemoryMax` values ("5242880") — `builtins.match` yields `null` (not `""`) for a non-participating optional group, and the multiplier dynamic-select threw; fixed to map `null → ""` (the `"" = 1` entry proves the intent). **The SystemNix fork of systemd.nix needs the same fix** (forked-during-migration divergence, first one). New negative-harness `lib` group (green control + lifecycle-guard-stripped + fs-guard-stripped) proves the tests bite — 22 cases total. aarch64-linux now evaluates every pure check (formatting, lib-eval, 4 contracts, module-list); only the 4 VM checks stay x86_64-only; eval portability proven with `nix flake check --all-systems --no-build`.
