# Changelog

All notable changes to the collection are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/).

- **docs: living-doc set built from code (2026-11-12)** — FEATURES.md (honest feature inventory with evidence), TODO_LIST.md (7 verified open items), ROADMAP.md (3 themes + non-goals), docs/DOMAIN_LANGUAGE.md (glossary); README Modules section populated (scaffold placeholder shipped two modules late); SECURITY.md practices corrected (claimed CI security scanning — no CI exists; checks run via `nix flake check`); AGENTS.md session context added.
- **tests: negative mutation harness (2026-11-12)** — `tests/negative/run.sh`, the copy-mutate-prove harness ported from SystemNix `scripts/negative-test-lints.sh`: copy the git-tracked tree without `.git`, apply ONE sed mutation per case, build the check from the copy, require the contract MARKER in the failure. Ships the `bootmirror` group (green control + 4 mutation legs) proving the boot-mirror self-assertions bite. Manual by design (`nix build --impure` cannot run inside flake checks); `CASES=` filter and `KEEP=1` triage knobs.
- **boot-mirror: 2nd module, extracted from SystemNix (2026-11-12)** — verified byte-mirror of the primary systemd-boot ESP on a 2nd boot disk: oneshot `boot-mirror-sync` (bootctl install on the mirror, reverse-propagation of loader-owned boot-counting renames before the forward rsync, `diff -r` verification gate that refuses a drifted mirror), a path unit re-triggering on ANY loader-entries change (covers raw `switch-to-configuration` gen-installs), `nofail` mount + condition-skip posture (a detached mirror degrades, never blocks boot). Contract is eval-pinned: module self-assertions + the fixture-host eval check `checks.x86_64-linux.boot-mirror-contract`.
- **wifi-failover: first module, extracted from SystemNix (2026-11-11/12)** — the pilot wave of the collection plan: `modules/wifi-failover/` (module + colocated `watch.sh` + README), the 5-scenario VM test (`checks.x86_64-linux.wifi-failover-vm`, veth peer admin-state = cable carrier), and the systemd lib spine (`lib/` — harden, serviceDefaults family, unit generators, `unitExecText`/`extractPortLiterals` audit scan surface; forked-during-migration from SystemNix's `lib/default.nix`, byte-parity proven at extraction). New vs the SystemNix original: a `gateway` option (nullOr str; null derives from `networking.defaultGateway`, eval-time assertion + graceful placeholder) replacing the `networking.local.gateway` fleet coupling. SystemNix consumes it at rev `0a8d9731` through a delegation layer; parity proven twice (semantic unit-diff empty + build-level script content identity). Rev `0a8d973` is the SystemNix-locked snapshot; later tree churn is formatting only.
