Checks: 2 eval-contract checks + 3 VM tests (journal 2-node, caddy 2-node incl. the dependency-death degradation, migrate full behavior matrix); negative harness grows `hottier` (5 legs) + `hotdirmigrate` (5 legs). Design lesson banked: dynamic config KEYS from option values (fileSystems.${m.mountPoint}) at config top level recurse infinitely — static top-level keys with the mapping inside their values is the canonical shape.
